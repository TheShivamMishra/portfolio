# Shivam Mishra — Portfolio

Personal portfolio for Shivam Mishra, Senior Software Engineer.

## Live site

GitHub Pages: https://theshivammishra.github.io/portfolio/

## Structure

- `index.html`: profile, experience, projects, links, and metadata
- `styles.css`: responsive layout, typography, colors, and interaction styles
- `script.js`: active-section navigation
- `assets/`: local fonts, favicon, license, and downloadable resume

The site is intentionally buildless. Update the files on the `main` branch and GitHub Pages will publish the changes automatically.
